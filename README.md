# 🧮 C++ Calculator

A simple and interactive **console-based calculator built with C++**. This project demonstrates fundamental C++ programming concepts through a practical application that performs different mathematical operations while handling invalid input and common errors.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 📊 Percentage
* 🔢 Power
* √ Square root
* 🔄 Perform multiple calculations in one session
* ⚠️ Input validation
* 🚫 Division-by-zero protection
* 📋 Menu-driven interface

## 🛠️ Tech Stack

* **C++**
* **Standard C++ Library**
* **Console / Terminal**

## ▶️ How to Run

### Clone the repository

```bash
git clone (https://github.com/carlarizk04-web/cpp-calculator)
```

### Compile the program

Using `g++`:

```bash
g++ calculator.cpp -o calculator
```

### Run the program

**Windows:**

```bash
calculator.exe
```

**Linux / macOS:**

```bash
./calculator
```

## 💻 Example

```text
=================================
       C++ CALCULATOR
=================================

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Percentage
6. Power
```

The user selects an operation, enters the required values, and receives the calculated result. The program can continue running so multiple calculations can be performed without restarting it.
